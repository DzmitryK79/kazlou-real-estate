# Источники KAZLOU Interactive Advisory
Обновлено: 2026-10-21

## Правила
- Для каждой цифры указывать исходную дату публикации и текущий статус: факт, строится, утверждено, цель или модель.
- Не смешивать цены объявлений и зарегистрированные сделки.
- Не рисовать линии метро или границы районов по памяти. Для карты использовать только проверенную геометрию и указывать источник.
- DXB Interact: использование доступной веб-аналитики; автоматическое получение закрытых данных требует разрешённого доступа.
- Для иллюстраций и официальных рендеров отдельно проверять права публикации.

## Очередь для внедрения
1. Проверить и загрузить точные полигоны границ семи эмиратов.
2. Подготовить официальную геометрию Blue Line по станциям и линиям; не создавать художественных трасс.
3. Нанести пять центров Dubai 2040 с источниками.
4. Подключить CSV DLD для расчётов сравнимых объектов.
5. При наличии права использования добавить высококачественные рендеры и фотографии.
